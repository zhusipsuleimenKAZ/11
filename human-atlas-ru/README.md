# Атлас человека (RU · LAT)

Русская версия интерактивного 3D-атласа [ashemag/human-atlas](https://github.com/ashemag/human-atlas): интерфейс на русском, у каждой из 2 234 структур есть русское и латинское название. Поиск работает по-русски, на латыни и по-английски.

## Что изменено по сравнению с оригиналом

- `app/names-ru-la.json`: словарь на 2 048 базовых терминов. Для каждого английского термина FMA указаны русское название, его род, латинское название и его род.
- `app/i18n.ts`: собирает полное название. «Левый/правый» согласуется по роду (*левая бедренная кость*, *femur sinistrum*). Если сторона стоит в середине термина, она добавляется в конце: «(слева)», «(sin.)». Такие термины, как *left ventricle* или *right coronary artery*, остаются цельными.
- `app/page.tsx`, `app/anatomy.ts`, `app/scene.tsx`: интерфейс, названия систем и описания переведены на русский.
- Пути к файлам модели сделаны относительными, поэтому сборку можно открыть из любой папки.

Латинские названия даны по образцу Terminologia Anatomica. У служебных групп атласа (например, «участок артерии») официального латинского термина нет, и для них латынь описательная.

## Запуск

Файлы геометрии (`body-*.bin.gz`, около 33 МБ) в репозиторий не входят. Их нужно взять из оригинального проекта:

```sh
git clone --depth 1 https://github.com/ashemag/human-atlas.git /tmp/human-atlas
cp /tmp/human-atlas/public/models/body-*.bin.gz public/models/
npm ci
npm run dev        # http://localhost:3016
```

Статическая сборка: `npx vite build --base ./`, результат появится в `dist/`. Если хостинг не принимает файлы `.gz`, после сборки выполните `python3 scripts/artifact-models.py`. Скрипт перекодирует модели в `.txt` (base64), а загрузчик раскодирует их обратно.
